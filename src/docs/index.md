# Vortex Foundation Project Overview

## About
Vortex Foundation is a Web3 project launched in 2021 focused on enriching the Fantom ecosystem through AI-powered NFT trading and community engagement.

## Core Products

### 1. Oracle NFTs
- Collection of 100 AI-generated unique black hole NFTs
- Currently available on Paintswap marketplace
- Migrateable to Sonic Chain
- Revenue sharing implementation planned

### 2. $VORTEX Token
- Fair launched token
- Total supply: 10M
- Available on Equalizer/WAGMI
- Contract: `0xf316A1cB7376021ad52705c1403DF86C7A7A18d0`

### 3. Vortex AI System
The platform features three main AI components:

#### NFT Trading Assistant
- Real-time floor price analysis
- Automated buying/selling
- Market monitoring
- Trend predictions
- Portfolio optimization

#### Twitter Agent
- Multi-agent personality system
- Content analysis capabilities
- Media processing
- Advanced contextual awareness

#### Telegram Agent
- Real-time messaging
- NFT trading insights
- Alert systems
- Conversation summarization
